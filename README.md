# first_repo

A minimal Python repository demonstrating how to define and call a function.

## Contents

- `my_function.py`: defines `my_function()`, which prints a greeting.

## Requirements

Python 3. No external packages are required.

## How to use

From the repository directory, run:

```bash
python -c "from my_function import my_function; my_function()"
```

Expected output:

```text
Hello from my function!
```
